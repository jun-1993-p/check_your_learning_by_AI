# 코드는 별도 저장소에 두고, 코드 포함 출제는 보류

코드 블록은 `.data/bookN/code_blocks.jsonl`에 따로 두고 문단에는 `code_ids`로만 연결해요. LLM에 주는 문단 본문에서는 코드를 빼고, 임베딩 텍스트에만 앞 8줄을 넣어요. 평가에서 코드 문단의 오답률이 높았고 원본 코드에 마커·입출력 오분리가 있어 보정만으로는 안전하지 않다고 봤어요 (2026-10-08).

## Consequences

- 코드 오염(`[[MARK]]`, 이어쓰기 줄, 종류 오분류)은 문단 단계가 아니라 정제 단계(`text_refine.py`)에서 고쳐요.
- 평가는 `EXCLUDE_CODE=True`로 코드 문단을 빼요. 샌드박스 실행 검증은 하지 않아요.
