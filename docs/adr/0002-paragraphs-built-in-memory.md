# 문단은 파일로 저장하지 않고 chunks.jsonl에서 매번 만든다

`paragraphs.jsonl`을 폐기하고, A+ 문단은 `chunks.jsonl`(이름과 달리 한 줄 = 페이지 하나의 블록 구조)에서 메모리로 만들어요. 책 전체에 약 0.1초라 저장할 이득이 없고, 규칙이 바뀌면 임베딩 텍스트 해시가 달라져 증분 임베딩이 바뀐 문단만 다시 만들어요. 문단 id는 블록 위치 기반 `{페이지}-01#b{시작 블록}`이라 앞에 문단이 끼어도 뒤 id가 밀리지 않아요.

## Consequences

- `chunks.jsonl`의 "chunk"는 옛 이름이에요. 검색 단위는 A+ 문단이에요.
- 규칙이 확정되면 정제 단계에서 문단 구간을 `chunks.jsonl`에 저장하는 안을 다시 검토해요.
