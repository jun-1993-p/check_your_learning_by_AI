# 근거·출제 단위는 A+ 문단 하나

2026-10-07~08에 근거 단위를 문장 → 문단으로 바꾸고, 문단 후보 A(설명 블록만)·B(+뒤 코드)·C(소제목 구간)와 조각 인덱스를 시험한 끝에 A+ 문단 하나로 확정했어요. 문장 단위는 문맥 부족·예제 이름 때문에 거부가 많았고, A는 빈칸이 많은 약한 문제를, B는 짧은 문단 때문에 빈칸 2~4개 문제를 냈어요. 앱 답변(`quiz_session.py`)도 같은 문단 인덱스를 써요.

## Considered Options

- 목표 길이 200/350/500자를 30케이스로 비교: 출제 성공 30/28/26이라 200자(`PLUS_TARGET_CHARS=200`, 상한 600자)로 정했어요.
- 문장 단위로 다시 쪼개는 전환은 하지 않아요.
