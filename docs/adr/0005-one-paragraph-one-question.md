# 앱 퀴즈는 유형과 관계없이 "문단 하나 → LLM 문제 하나"

O/X·빈칸·4지선다·단답형 모두 문단 하나를 LLM에 주고 문제 하나를 받아요. 문단은 인용 문단과 같은 페이지의 다른 문단을 약 2:1로 섞어요. 모든 유형에서 LLM이 근거 인용을 문단에서 그대로 복사하게 하고, 코드가 그 구절(빈칸·단답형은 정답도)이 문단에 있는지 검사해요. 코드로 함수 이름을 가리던 옛 빈칸 방식은 문단 안 코드만 쓰면 재료가 거의 없어서 폐기했어요 (10개 질문에 9개).

## Considered Options

- 출제 못함을 줄이려는 사다리 폴백(다른 페이지로 확장, 재시도 5회, 코드·O/X 폴백)과 허용률 목표는 모두 채택하지 않았어요. 문단 최대 3순위까지 시도하고 못 내면 출제 못함으로 끝내요.
