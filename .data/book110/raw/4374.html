주가이동평균을 계산하기 위해 먼저 DataReader를 통해 일자별 데이터를 DataFrame 객체로 저장합니다. 

In [84]: import pandas as pd

In [85]: import pandas_datareader.data as web

In [86]: gs = web.DataReader("078930.KS", "yahoo", "2014-01-01", "2016-03-06")

앞의 예에서는 datetime 모듈을 이용해 조회 기간을 입력했는데 예제에서는 조회 기간의 시작일과 종료일을 직접 입력했습니다. 이 경우에는 datetime과 달리 날짜에 0을 넣거나 빼도 잘 인식합니다.

데이터가 잘 받아졌는지 확인하기 위해 tail 메서드를 호출해서 끝부분에 위치하는 5개의 데이터를 확인합니다.

수정 종가에 대해 5일 주가 이동평균을 계산하려면 다음과 같이 코드를 작성합니다.

In [88]: ma5 = gs['Adj Close'].rolling(window=5).mean()

ma5 객체의 타입을 보면 pandas의 Series임을 확인할 수 있습니다. 앞서 설명한 것처럼 이동평균은 각 일자에 계산되는 값이므로 결괏값이 매우 많습니다. tail 메서드를 사용해 뒤에서부터 10개의 값만 확인해 봅시다.

tail 메서드의 리턴 값을 표 13.2에서 계산한 주가이동평균과 비교해보면 2016-03-01부터 값이 다른 것을 확인할 수 있습니다. 3월 1일은 삼일절로 공휴일이기 때문에 주식시장이 열리지 않습니다. 따라서 해당 일의 로우 데이터는 DataFrame 객체에서 빼고 계산해야 합니다.

공휴일처럼 주식 시장이 열리지 않았던 일자의 데이터를 DataFrame 객체에서 제거하기 위해 먼저 gs.tail()을 사용해 해당 일의 데이터의 특징을 살펴봅시다. 2016-03-01 로우를 살펴보면 거래량(Volume)이 0인 것을 확인할 수 있습니다.

In [128]: gs['Volume'] != 0
