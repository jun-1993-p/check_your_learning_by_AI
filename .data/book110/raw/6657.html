3) 급등주 포착 알고리즘 구현

광고가 출력될 위치입니다.
광고가 출력될 위치입니다.

알고리즘 구현에 필요한 데이터가 모두 준비됐으니 이번에는 알고리즘을 구현해 보겠습니다. ‘급등주 포착’ 알고리즘은 특정 거래일의 거래량이 이전 시점의 평균 거래량보다 1,000% 이상 급증하는 종목을 매수하는 것입니다.

사실 기존의 주식 관련 책에서 소개하는 기법은 알고리즘 구현 관점에서 조금 불분명한 부분들이 많습니다. 이 책에서는 일단 ‘이전 시점의 평균 거래량’을 특정 거래일 이전의 20일(거래일 기준) 동안의 평균 거래량으로 정의했습니다. 그리고 ‘거래량 급증’은 특정 거래일의 거래량이 평균 거래량보다 1,000% 초과일 때 급등한 것으로 정의했습니다.

알고리즘을 구현에 맞춰 상세화했다면 이를 파이썬 코드로 구현하면 됩니다. 급등주 포착을 체크하는 기능이기 때문에 메서드 이름을 check_speedy_rising_volume으로 지정했고 메서드의 인자로 종목코드를 전달받게 했습니다. 코드는 다음과 같습니다.

def check_speedy_rising_volume(self, code):
    today = datetime.datetime.today().strftime("%Y%m%d")
    df = self.get_ohlcv(code, today)
    volumes = df['volume']

    if len(volumes) < 21:
        return False

    sum_vol20 = 0
    today_vol = 0

    for i, vol in enumerate(volumes):
        if i == 0:
            today_vol = vol
        elif 1 <= i <= 20:
            sum_vol20 += vol
        else:
            break

    avg_vol20 = sum_vol20 / 20
    if today_vol > avg_vol20 * 10:
        return True

위 코드를 조금씩 나눠서 분석해 보겠습니다. 가장 먼저 오늘 날짜를 가져왔습니다. 파이썬 코드에서 오늘 날짜를 '20170321'과 같은 포맷으로 얻기 위해 datetime 모듈을 사용했습니다.

today = datetime.datetime.today().strftime("%Y%m%d")

종목코드와 조회 시작일이 준비됐으므로 앞서 구현한 get_ohlcv 메서드를 호출해서 해당 종목에 대한 시가, 고가, 저가, 종가, 거래량 데이터를 DataFrame 객체로 얻어온 후 그중 거래량 칼럼만 바인딩했습니다.

df = self.get_ohlcv(code, today)
volumes = df['volume']

조회 시작일을 기준으로 이전 20일간 거래량의 평균을 계산해야 하므로 총 21일 치의 데이터가 필요합니다. 만약 최근에 상장된 종목이라면 데이터가 충분하지 않을 수 있으므로 이 경우에는if 문을 사용해 걸러냈습니다. check_speedy_rising_volume 메서드는 해당 종목이 거래량 기준 급등주인 경우 True를 반환하고 급등주가 아닌 경우에는 False를 반환합니다. 따라서 데이터가 충분하지 않은 종목에 대해서는 False를 반환합니다.

if len(volumes) < 21:
    return False

조회 시작일의 거래량은 today_vol이라는 변수로 저장하고 조회 시작일을 기준으로 이전 20일의 거래량은 평균을 계산하기 위해 먼저 sum_vol20을 통해 일별 거래량을 누적했습니다. 구현하고 있는 알고리즘은 21일 치 데이터만 필요하므로 for 문에서 break를 통해 반복문을 탈출하도록 구현했습니다. 이를 통해 쓸데없는 데이터에 대해 반복문을 수행하지 않게 할 수 있습니다.

sum_vol20 = 0
today_vol = 0

for i, vol in enumerate(volumes):
    if i == 0:
        today_vol = vol
    elif 1 <= i <= 20:
        sum_vol20 += vol
    else:
        break

마지막으로 20일의 평균 거래량을 계산한 후 조회 시작일의 거래량과 비교합니다. 만약 조회 시작일의 거래량이 평균 거래량을 1,000% 초과한다면 True를 반환하도록 구현합니다.

avg_vol20 = sum_vol20 / 20
if today_vol > avg_vol20 * 10:
    return True

구현한 check_speedy_rising_volume 메서드를 테스트하기 위해 run 메서드를 다음과 같이 수정합니다. 코스닥 시장에 대해 급등주 포착 알고리즘에 부합하는 종목이 있는지 확인하고 만약 있다면 이를 화면에 출력하게 했습니다.

def run(self):
    num = len(self.kosdaq_codes)

    for i, code in enumerate(self.kosdaq_codes):
        print(i, '/', num)
        if self.check_speedy_rising_volume(code):
            print("급등주: ", code)

import sys
from PyQt5.QtWidgets import *
import Kiwoom
import time
from pandas import DataFrame
import datetime

MARKET_KOSPI   = 0
MARKET_KOSDAQ  = 10

class PyMon:
    def __init__(self):
        self.kiwoom = Kiwoom.Kiwoom()
        self.kiwoom.comm_connect()
        self.get_code_list()

    def get_code_list(self):
        self.kospi_codes = self.kiwoom.get_code_list_by_market(MARKET_KOSPI)
        self.kosdaq_codes = self.kiwoom.get_code_list_by_market(MARKET_KOSDAQ)

    def get_ohlcv(self, code, start):
        self.kiwoom.ohlcv = {'date': [], 'open': [], 'high': [], 'low': [], 'close': [], 'volume': []}

        self.kiwoom.set_input_value("종목코드", code)
        self.kiwoom.set_input_value("기준일자", start)
        self.kiwoom.set_input_value("수정주가구분", 1)
        self.kiwoom.comm_rq_data("opt10081_req", "opt10081", 0, "0101")
        time.sleep(0.2)

        df = DataFrame(self.kiwoom.ohlcv, columns=['open', 'high', 'low', 'close', 'volume'],
                       index=self.kiwoom.ohlcv['date'])
        return df

    def check_speedy_rising_volume(self, code):
        today = datetime.datetime.today().strftime("%Y%m%d")
        df = self.get_ohlcv(code, today)
        volumes = df['volume']

        if len(volumes) < 21:
            return False

        sum_vol20 = 0
        today_vol = 0

        for i, vol in enumerate(volumes):
            if i == 0:
                today_vol = vol
            elif 1 <= i <= 20:
                sum_vol20 += vol
            else:
                break

        avg_vol20 = sum_vol20 / 20
        if today_vol > avg_vol20 * 10:
            return True

    def update_buy_list(self, buy_list):
        f = open("buy_list.txt", "wt")
        for code in buy_list:
            f.writelines("매수;", code, ";시장가;10;0;매수전")
        f.close()

    def run(self):
        buy_list = []
        num = len(self.kosdaq_codes)

        for i, code in enumerate(self.kosdaq_codes):
            print(i, '/', num)
            if self.check_speedy_rising_volume(code):
                buy_list.append(code)

        self.update_buy_list(buy_list)

if __name__ == "__main__":
    app = QApplication(sys.argv)
    pymon = PyMon()
    pymon.run()
