4) 배당률 기반 투자 알고리즘 구현(1)

광고가 출력될 위치입니다.
광고가 출력될 위치입니다.

이번 절에서는 국채시가배당률 기반의 매매 알고리즘을 구현해 보겠습니다. 앞서 설명한 것처럼 국채시가배당률을 계산하려면 현금배당수익률과 3년 만기 국채 수익률이 필요합니다.

$$국채시가배당률(배)= {현금배당수익률 \over 3년만기국채수익률}$$

현금 배당 수익률은 주당배당금(DPS; Dividend per Share)을 주가로 나눈 후 100을 곱한 값입니다.

$$현금배당수익률(\%) = {주당배당금 \over 주가} \times 100 $$

어떤 기업의 현금 배당이 연말결산 후 4월에 한 번 지급된다고 가정하면 주당배당금은 다음 배당 전까지는 변하지 않는 값입니다. 이와 달리 주가는 거래일마다 변동되는 값이므로 어떤 시점의 주가를 사용했는가에 따라 현금배당수익률은 달라질 수 있습니다.

$$주당배당금= {배당금 총액 \over 발행주식수}$$

국채시가배당률 기반의 투자는 나름 논리적이지만 이를 당장 시스템 트레이딩으로 구현하기에는 몇 가지 어려움이 있습니다. 첫 번째는 주당배당금이라는 것이 과거의 값이라는 점입니다. 기업이 일년 동안 영업하고 난 결과에 대해 배당 여부를 결정하기 때문에 현 시점에서는 이번 영업 연도에 배당이 진행될지, 그리고 얼마만큼 현금 배당이 나올지 알 수가 없습니다.

두 번째는 웹 사이트를 통해 제공되는 현금배당수익률은 분모에 사용되는 주가가 현재 시점의 주가가 아니라 과거 시점(배당기준일)의 일정 기간 동안의 주가일 수 있다는 점입니다. 만약 웹 사이트가 현금배당수익률의 계산에 사용됐던 시점의 주가보다 현재 주가가 큰 폭으로 올랐다면 웹 사이트 등을 통해 제공된 현금배당수익률을 그대로 사용할 수는 없습니다.

세 번째는 3년 만기 국채 수익률도 1년에 한 번 제공되는 값이라는 것입니다. 따라서 일 단위로 알고리즘을 동작시키는 경우 데이터가 변동되지 않기 때문에 동일한 결과가 나올 것입니다. 쉽게 말하면 일년에 딱 한번 매매 신호가 발생하고 나머지 기간 동안에는 동일한 신호가 발생합니다.

먼저 첫 번째 문제의 해결책부터 생각해보겠습니다. 미래의 주당 배당금을 알 수 있는 방법은 없습니다. 다만 기업도 순이익이 있어야 배당을 할 수 있기 때문에 증권사에서 제공하는 추정 실적을 통해 주당배당금을 어느 정도 예측할 수는 있습니다.

두 번째 문제는 웹 사이트를 통해 제공되는 현금배당수익률이 어떻게 계산됐는지 확인하면 됩니다. 만일 현금배당수익률이 배당 기준일의 주가를 토대로 계산됐다면 웹 사이트를 통해 현금배당수익률 데이터를 얻는 것이 아니라 직접 추정 실적을 바탕으로 거래일마다 예상 주당배당금과 종가를 사용해 예상 현금배당수익률을 계산하면 될 것입니다.

세 번째 문제의 해결책은 간단합니다. 사실 3년 만기 국채 수익률은 일별 시세가 존재합니다. 앞서 연도별 값은 일별 시세의 산술평균 값입니다. 따라서 매일 3년 만기 국채 수익률의 일별 시세를 조회한다면 거래일별로 최신 데이터를 확보할 수 있습니다.

국채시가 배당률이라는 간단한 아이디어도 이를 구현하려다 보면 많은 곳에서 구체화가 필요하다는 점을 알 수 있습니다. 말로는 간단할지 몰라도 이를 프로그램으로 구현하려면 모든 것이 구체적이고 정확해야 합니다.

def get_dividend_yield(code):
    url = "http://companyinfo.stock.naver.com/company/c1010001.aspx?cmp_cd=" + code
    html = requests.get(url).text

    soup = BeautifulSoup(html, 'html5lib') 
    dt_data = soup.select("td dl dt")

    dividend_yield = dt_data[-2].text 
    dividend_yield = dividend_yield.split(' ')[1] 
    dividend_yield = dividend_yield[:-1]

    return dividend_yield

def get_previous_dividend_yield(code):
    dividend_yield = get_financial_statements(code)  

    now = datetime.datetime.now()
    cur_year = now.year

    previous_dividend_yield = {}

    for year in range(cur_year-5, cur_year):
        if str(year) in dividend_yield.index:
            previous_dividend_yield[year] = dividend_yield[str(year)]

    return previous_dividend_yield
