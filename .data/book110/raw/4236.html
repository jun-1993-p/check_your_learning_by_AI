그림 12.20 Hello PyQt

먼저 PyCharm을 실행한 후 예제 12.1의 코드를 입력해 보기 바랍니다. 코드를 모두 입력했다면 Ctrl + F9와 같은 단축키를 이용해 작성된 코드를 실행해 봅니다. 작성한 코드에 오타가 없다면 그림 12.20과 같은 창이 화면에 나타날 것입니다.

import sys
from PyQt5.QtWidgets import *

app = QApplication(sys.argv)
label = QLabel("Hello PyQt")
label.show()
app.exec_()

예제 12.1 Hello PyQt 코드(소스코드: book/ch12/01.py)

예제 12.1을 살펴보면 공백을 포함해서 단 7줄의 코드로 윈도우를 만들고 그 안에 'Hello PyQt'라는 문자열을 출력했습니다. 특히 처음 두 줄은 모듈을 임포트하는 구문으로, 실제로 윈도우를 생성하는 코드는 딱 4줄입니다. 어떤가요? GUI 프로그래밍이 생각보다 어렵지 않지요?

일단 프로그램의 정상적인 실행 결과를 확인했다면 예제 12.1을 자세히 분석해 보겠습니다. 예제 12.1에서 첫 두 줄은 모듈을 임포트하는 역할을 합니다. 이때 첫 번째 줄과 두 번째 줄은 모듈을 임포트하는 방식이 조금 다릅니다.

5장에서 다뤘듯이 ‘import 모듈명’과 같은 방식으로 모듈을 임포트했다면 모듈(파이썬 파일) 내에 정의된 변수, 함수, 클래스에 접근할 때 ‘모듈명.변수’와 같이 모듈 이름을 명시해야 합니다.

이와 달리 'from PyQt5.QtWidgets import *'와 같은 방식은 PyQt5라는 디렉터리의 QtWidgets 파일에 있는 모든 것 (*)을 import 하라는 의미이므로 해당 모듈 (QtCore)에 정의된 변수, 함수, 클래스를 모듈 이름을 통해 접근할 필요 없이 바로 사용할 수 있습니다.

참고로 그림 12.21을 참조하면 PyQt5.QtWidgets는 QtWidgets.pyd라는 이름으로 'C:\Anaconda3\Lib\site-packages\PyQt5' 디렉터리에 위치합니다. 파이썬 모듈은 파이썬 코드(*.py) 뿐 아니라 *.pyd 파일 형태도 사용될 수 있는데 여기서 *.pyd 파일은 윈도우의 *.dll과 같습니다. 이처럼 일부 모듈은 성능을 위하여 파이썬으로 모듈을 구현하는 것이 아니라 C라는 프로그래밍 언어로 구현하고 파이썬에서 C 모듈을 임포트해서 사용하기도 합니다.

그림 12.21 QtGui.pyd 파일의 위치

예제 12.1에서 윈도우 생성과 직접 관련된 네 줄의 코드에 대한 실행 흐름을 그림으로 나타내면 그림 12.22와 같습니다. 먼저 QApplication 클래스에 대한 인스턴스를 생성하고 이를 app이라는 변수로 바인딩합니다. app을 통해 exec_ 메서드를 호출하면 프로그램은 이벤트 루프(event loop)에 진입합니다.

이벤트 루프란 무한 반복하면서 이벤트를 처리하는 상태를 의미합니다. 앞서 여러 번 설명했듯이 파이썬 코드는 위에서 밑으로 순서대로 실행된 후 프로그램이 종료됩니다. 따라서 예제 12.1의 코드가 실행되면 그림 12.20과 같이 윈도우가 화면에 계속 출력됩니다.

앞에서 작성한 대부분의 TUI 기반의 프로그램은 프로그램이 실행된 후 종료됐지만 그림 12.20과 같은 GUI 프로그램은 사용자가 윈도우를 닫기 전까지는 계속 실행된 상태로 남아 있습니다. 이처럼 프로그램이 종료되지 않고 실행 상태로 계속 남아 있을 수 있는 이유가 바로 이벤트 루프 때문입니다.

이벤트 루프는 기본적으로 무한 루프 구조이며, 무한 루프 상태에서 사용자가 발생한 이벤트를 그때그때 처리해줍니다. 예를 들어, 사용자가 윈도우를 클릭하면 ‘클릭 이벤트’가 발생하는데 이때 이벤트 루프에서 ‘클릭 이벤트’를 처리 해주는 것입니다.

그림 12.22 PyQt 코드 실행 흐름

그림 12.22에서 중간에 위치하는 네모 박스는 윈도우를 만들고 이를 화면에 보이게 하는 파이썬 코드로 구성돼 있습니다. QApplication 클래스의 인스턴스가 GUI 프로그램을 전반적으로 제어하는 역할을 한다면 네모 박스 부분은 UI 구성을 담당합니다.

예제 12.1에서는 네모 박스 위치에 해당하는 코드에서 QLabel 클래스의 인스턴스를 만들고 해당 인스턴스의 show 메서드를 호출함으로써 화면에 Qlabel 위젯이 출력되는 것입니다. 만약 네모 박스 위치에 해당하는 코드를 수정하면 다른 형태의 윈도우가 출력되게 할 수 있습니다.

예를 들어, 다음 코드를 실행하면 그림 12.23과 같이 윈도우에 버튼이 하나 위치하는 프로그램이 나타납니다. 예제 12.1과 비교해보면 단순히 이벤트 루프가 실행되기 전에 윈도우 창을 구성하는 코드가 있다는 점을 확인할 수 있습니다.

import sys
from PyQt5.QtWidgets import *

app = QApplication(sys.argv)
label = QPushButton("Quit")
label.show()
