06-5 숫자 야구 게임 만들기

광고가 출력될 위치입니다.
광고가 출력될 위치입니다.

이번에는 컴퓨터와 대결하는 숫자 야구 게임을 만들어 보자. 숫자 야구는 상대방이 정한 서로 다른 3자리 숫자를 맞히는 게임이다. 숫자를 추측하면 스트라이크와 볼로 힌트를 알려주고, 이 힌트를 바탕으로 정답을 찾아가는 것이 이 게임의 핵심이다.

3자리 숫자 중 0은 제외한다.

게임의 규칙은 다음과 같다.

판정 조건
스트라이크 숫자와 위치가 모두 맞음
볼 숫자는 맞지만 위치가 다름

예를 들어 정답이 324일 때 132를 입력하면 숫자 3은 있지만 위치가 다르므로 볼, 숫자 2는 있지만 위치가 다르므로 볼이다. 따라서 결과는 0스트라이크 2볼이 된다. 만약 325를 입력하면 3과 2는 숫자와 위치가 모두 맞으므로 2스트라이크, 5는 정답에 없으므로 결과는 2스트라이크 0볼이 된다.

  • 필요한 기능은? 서로 다른 3자리 난수 생성, 스트라이크/볼 판정, 반복 입력
  • 입력받는 값은? 사용자가 추측한 3자리 숫자
  • 출력하는 값은? 스트라이크, 볼 개수 (정답이면 축하 메시지와 시도 횟수)

1. 먼저 컴퓨터가 서로 다른 3자리 숫자를 만들도록 해 보자.

# c:/doit/baseball.py
import random

nums = random.sample(range(1, 10), 3)
print(nums)

random.sample 함수는 주어진 범위에서 중복 없이 원하는 개수만큼 뽑아 리스트로 반환한다. range(1, 10)은 1부터 9까지의 숫자이므로 0은 포함되지 않는다.

실행하면 다음과 비슷하게 출력된다.

[3, 7, 1]

2. 이제 사용자에게 숫자를 입력받도록 코드를 추가해 보자.

# c:/doit/baseball.py
import random

nums = random.sample(range(1, 10), 3)

[[MARK]]question = input("3자리 숫자를 입력하세요: ")
print(question)[[/MARK]]

input 함수로 사용자에게 3자리 숫자를 입력받았다. 여기서 주의할 점은 input 함수가 반환하는 값은 문자열이라는 것이다. 예를 들어 "123"을 입력하면 question에는 문자열 "123"이 저장된다.

3. 입력받은 문자열을 숫자 리스트로 변환해야 컴퓨터의 숫자와 비교할 수 있다. 다음과 같이 코드를 수정해 보자.

# c:/doit/baseball.py
import random

nums = random.sample(range(1, 10), 3)

question = input("3자리 숫자를 입력하세요: ")
[[MARK]]guess = list(map(int, question))
print(guess)[[/MARK]]

map(int, question)은 문자열 "123"의 각 문자 "1", "2", "3"에 int 함수를 적용하여 정수 1, 2, 3으로 변환한다. 이것을 list로 감싸면 [1, 2, 3]이라는 리스트가 된다.

실행하면 다음과 같이 동작한다.

3자리 숫자를 입력하세요: 123
[1, 2, 3]

4. 이제 핵심인 스트라이크와 볼을 판정하는 코드를 작성해 보자.

# c:/doit/baseball.py
import random

nums = random.sample(range(1, 10), 3)

question = input("3자리 숫자를 입력하세요: ")
guess = list(map(int, question))

[[MARK]]strike = 0
ball = 0

for i in range(3):
    if guess[i] == nums[i]:
        strike += 1
    elif guess[i] in nums:
        ball += 1

print(f"{strike}스트라이크 {ball}볼")[[/MARK]]

for문으로 3자리를 차례대로 비교한다. guess[i] == nums[i]는 같은 위치에 같은 숫자가 있는지 확인하는 것으로 이 경우가 스트라이크이다. guess[i] in nums는 숫자가 정답에 포함되어 있지만 위치가 다른 경우로 이것이 볼이다. elif를 사용했으므로 스트라이크로 판정된 숫자는 볼로 중복 판정되지 않는다.

실행하면 다음과 같이 판정 결과가 출력된다.

3자리 숫자를 입력하세요: 123
1스트라이크 1볼

5. 하지만 지금은 한 번만 추측하고 끝난다. 정답을 맞힐 때까지 반복해서 입력받을 수 있도록 while문을 추가해 보자.

# c:/doit/baseball.py
import random

nums = random.sample(range(1, 10), 3)
[[MARK]]count = 0[[/MARK]]

[[MARK]]while True:[[/MARK]]
    question = input("3자리 숫자를 입력하세요: ")
    guess = list(map(int, question))
    [[MARK]]count += 1[[/MARK]]

    strike = 0
    ball = 0

    for i in range(3):
        if guess[i] == nums[i]:
            strike += 1
        elif guess[i] in nums:
            ball += 1

    [[MARK]]if strike == 3:
        print(f"정답! {count}번 만에 맞혔습니다.")
        break[[/MARK]]

    print(f"{strike}스트라이크 {ball}볼")

count 변수로 시도 횟수를 세고, 3스트라이크가 되면 축하 메시지와 함께 시도 횟수를 출력한 후 break로 반복을 종료한다. 3스트라이크가 아니면 스트라이크와 볼 개수를 알려주고 다시 입력을 받는다.
