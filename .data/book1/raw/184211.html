07-3 이터레이터와 제너레이터

광고가 출력될 위치입니다.
광고가 출력될 위치입니다.

파이썬으로 대량의 데이터를 처리하다 보면 메모리를 효율적으로 사용하고, 필요한 만큼만 데이터를 가져오는 방법이 필요하다. 이터레이터와 제너레이터는 이런 문제를 해결하는 파이썬의 핵심 도구이다.

다음은 리스트의 간단한 사용법이다.

for a in [1, 2, 3]:
    print(a)

리스트 [1, 2, 3]을 for 문으로 차례대로 하나씩 출력하는 예제이다. 이렇게 for 문과 같은 반복 구문에 사용할 수 있는 리스트와 같은 객체를 '반복 가능(iterable) 객체'라고 한다.

이터레이터란?

그렇다면 이터레이터(iterator)란 무엇일까? 이터레이터는 next() 함수로 값을 하나씩 꺼낼 수 있는 객체이다. 모든 값을 꺼내면 StopIteration 예외가 발생한다.

리스트는 반복 가능(iterable)하다는 것을 이미 알아보았다. 그렇다면 리스트는 이터레이터일까? 다음과 같이 확인해 보자.

>>> a = [1, 2, 3]
>>> next(a)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: 'list' object is not an iterator

리스트 a로 next 함수를 호출했더니 리스트는 이터레이터가 아니라는 오류가 발생한다. 즉, 반복 가능하다고 해서 이터레이터는 아니다.

비유하면 책(iterable)은 읽을 수 있는 대상이지만, 실제로 페이지를 한 장씩 넘기며 읽으려면 책갈피(iterator)가 필요한 것과 같다. 리스트는 데이터를 담고 있는 책이고, 이터레이터는 그 책에서 데이터를 하나씩 꺼내 주는 책갈피 역할을 한다.

반복 가능한 객체는 iter 함수를 이용해 이터레이터로 만들 수 있다.

>>> a = [1, 2, 3]
>>> ia = [[MARK]]iter(a)[[/MARK]]
>>> type(ia)
<class 'list_iterator'>

이제 리스트를 이터레이터로 변경했으므로 next 함수를 호출해 보자.

>>> next(ia)
1
>>> next(ia)
2
>>> next(ia)
3
>>> next(ia)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration

next 함수를 호출할 때마다 이터레이터의 요소를 차례대로 반환한다. 더 이상 반환할 값이 없으면 StopIteration 예외가 발생한다.

이터레이터의 값을 가져오는 가장 일반적인 방법은 for 문을 이용하는 것이다.

>>> a = [1, 2, 3]
>>> ia = iter(a)
>>> for i in ia:
...     print(i)
... 
1
2
3

for 문을 이용하면 next 함수를 직접 호출하거나 StopIteration 예외를 처리할 필요가 없다. for 문이 이 과정을 자동으로 처리하기 때문이다.

이번에는 다음과 같은 예를 살펴보자.

>>> a = [1, 2, 3]
>>> ia = iter(a)
>>> for i in ia:
...     print(i)
... 
1
2
3
>>> for i in ia:
...     print(i)
... 
>>>

이터레이터는 for 문을 이용하여 반복한 후에는 다시 반복해도 값을 가져오지 못한다. 즉, for 문이나 next로 값을 한 번 읽으면 다시 읽을 수 없다. 이터레이터는 현재 위치를 기억하며 앞으로만 진행하기 때문에, 모든 값을 꺼내고 나면 처음으로 되돌아갈 수 없기 때문이다. 다시 반복하려면 iter() 함수로 새로운 이터레이터를 만들어야 한다.

이터레이터 만들기

지금까지 iter 함수를 이용하여 리스트를 이터레이터로 변환했다. 이번에는 직접 클래스로 이터레이터를 만들어 보자.

이터레이터 클래스의 필수 메서드

  1. __iter__ 메서드: 이터레이터 객체 자신을 반환한다.
  2. __next__ 메서드: 다음 값을 반환하고, 더 이상 값이 없으면 StopIteration 예외를 발생시킨다.

__iter__와 __next__는 05-1에서 배운 __init__처럼 파이썬이 특별한 상황에서 자동으로 호출하는 메서드이다. iter() 함수를 호출하면 __iter__가, next() 함수를 호출하면 __next__가 자동으로 호출된다.

이 두 메서드를 구현하면 for 문이나 next() 함수에서 사용할 수 있는 이터레이터가 된다. 다음 예를 살펴보자.

# iterator.py
class MyIterator:
    def __init__(self, data):
        self.data = data
        self.position = 0

    def [[MARK]]__iter__[[/MARK]](self):
        return self

    def [[MARK]]__next__[[/MARK]](self):
        if self.position >= len(self.data):
            raise StopIteration
        result = self.data[self.position]
        self.position += 1
        return result

if __name__ == "__main__":
    i = MyIterator([1,2,3])
    for item in i:
        print(item)

MyIterator 클래스의 동작 원리를 살펴보자.

1. __init__ 메서드: 이터레이터를 초기화한다.

  • self.data: 반복할 데이터를 저장한다.
  • self.position: 현재 위치를 추적하는 변수이다(0부터 시작).

2. __iter__ 메서드: 이터레이터 객체 자신을 반환한다.

  • 이 메서드가 있어야 파이썬이 해당 객체를 반복 가능한 객체로 인식한다.
  • for 문, iter() 함수, next() 함수 등에서 사용하려면 반드시 구현해야 한다.
  • 보통 return self로 자기 자신을 반환한다.

3. __next__ 메서드: 다음 값을 반환한다.

  • self.position을 이용해 현재 위치의 값을 가져온다.
  • 위치를 하나씩 증가시킨다.
  • 더 이상 값이 없으면 StopIteration 예외를 발생시킨다.

이 코드를 실행하면 다음과 같은 결과를 확인할 수 있다.

1
2
3

이번에는 입력받은 데이터를 역순으로 출력하는 ReverseIterator 클래스를 만들어 보자(설명은 앞의 MyIterator와 동일하므로 생략한다).

# reviterator.py
class ReverseIterator:
    def __init__(self, data):
        self.data = data
        self.position = len(self.data) -1

    def __iter__(self):
        return self

    def __next__(self):
        if self.position < 0:
            raise StopIteration
        result = self.data[self.position]
        self.position -= 1
        return result

if __name__ == "__main__":
    i = ReverseIterator([1,2,3])
    for item in i:
        print(item)

이를 실행하면 다음과 같이 입력받은 데이터를 역순으로 출력한다.

3
2
1

제너레이터란?

제너레이터는 이터레이터를 쉽게 만들어 주는 함수이다.

이터레이터를 클래스로 만들려면 __iter__와 __next__ 메서드를 구현해야 한다. 하지만 제너레이터를 사용하면 함수 하나로 간단하게 이터레이터를 만들 수 있다.

점프 투 파이썬

제너레이터의 핵심 특징

  • 일반 함수와 비슷하지만 return 대신 yield 키워드를 사용한다.
  • yield를 만나면 값을 반환하고 함수 실행을 일시 정지한다.
  • 다시 호출하면 일시 정지했던 지점부터 계속 실행한다.
  • 마치 음악 플레이어의 재생/일시 정지 기능처럼 동작한다.

가장 간단한 제너레이터의 예를 살펴보자.

>>> def mygen():
...     [[MARK]]yield[[/MARK]] 'a'
...     [[MARK]]yield[[/MARK]] 'b'
...     [[MARK]]yield[[/MARK]] 'c'
... 
>>> g = mygen()

mygen 함수는 yield 구문을 포함하므로 제너레이터이다. 제너레이터 객체는 g = mygen()과 같이 제너레이터 함수를 호출하여 만들 수 있다. type 함수로 확인하면 g 객체가 제너레이터 타입이라는 것을 알 수 있다.

>>> type(g)
<class 'generator'>

이제 다음과 같이 제너레이터의 값을 차례대로 얻어 보자.

>>> next(g)
'a'

제너레이터 객체 g로 next 함수를 실행하면 mygen 함수의 첫 번째 yield 문에서 'a' 값을 반환한다. 제너레이터는 yield를 만나면 값을 반환하고 현재 상태를 그대로 기억한다. 마치 음악을 재생하다가 일시 정지 버튼으로 멈춘 것과 같다.

다시 next() 함수를 실행해 보자.

>>> next(g)
'b'

이번에는 두 번째 yield 문에서 'b' 값을 반환한다. 계속해서 next 함수를 호출하면 다음과 같은 결과가 출력된다.

>>> next(g)
'c'
>>> next(g)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration

mygen 함수에는 총 3개의 yield 문이 있으므로 네 번째 next를 호출하면 더 이상 반환할 값이 없어 StopIteration 예외가 발생한다.

제너레이터 표현식

이번에는 다음과 같은 예를 살펴보자.

# generator.py
def mygen():
    for i in range(1, 1000):
        result = i * i
        yield result

gen = mygen()

print(next(gen))
print(next(gen))
print(next(gen))

mygen 함수는 1부터 1,000까지 각각의 숫자를 제곱한 값을 순서대로 반환하는 제너레이터이다. 이 예제를 실행하면 총 3번의 next를 호출하므로 다음과 같은 결과가 나온다.

1
4
9

제너레이터는 yield를 이용한 함수로 만들 수 있지만, 다음과 같이 소괄호를 사용한 제너레이터 표현식으로 더 간단하게 만들 수도 있다.

gen = (i * i for i in range(1, 1000))

이 표현식은 mygen 함수로 만든 제너레이터와 똑같이 동작한다. 리스트 컴프리헨션 구문과 비슷하지만, 대괄호 [] 대신 소괄호 ()를 사용한다. 이를 '제너레이터 표현식(generator expression)'이라고 한다. 소괄호를 사용하지만 튜플을 만드는 것이 아니라 제너레이터 객체를 만든다는 점에 주의하자.

클래스 이터레이터와 제너레이터

클래스를 이용해 이터레이터를 작성하면 복잡한 동작을 구현할 수 있다. 반면 제너레이터를 이용하면 간단하게 이터레이터를 만들 수 있다. 따라서 이터레이터의 성격에 따라 클래스로 만들 것인지, 제너레이터로 만들 것인지 선택해야 한다.

간단한 경우라면 제너레이터 함수나 제너레이터 표현식을 사용하는 것이 가독성이나 유지 보수 측면에서 유리하다. 다음은 (i * i for i in range(1, 1000)) 제너레이터를 클래스로 구현한 예이다.

class MyIterator:
    def __init__(self):
        self.data = 1

    def __iter__(self):
        return self

    def __next__(self):
        if self.data >= 1000:
            raise StopIteration
        result = self.data * self.data
        self.data += 1
        return result

이렇게 간단한 경우라면 클래스보다는 제너레이터 표현식을 사용하는 것이 훨씬 간편하고 이해하기 쉽다.

제너레이터 활용하기

제너레이터가 실제로 어떤 도움이 되는지 구체적인 예제로 알아보자.

상황: 시간이 오래 걸리는 작업을 처리해야 하는데, 모든 결과가 필요하지 않은 경우

먼저 일반적인 리스트 컴프리헨션을 사용한 예제를 보자.

# generator2.py
import time

def longtime_job():
    print("job start")
    time.sleep(1)  # 1초 지연 - 실제로는 데이터베이스 조회, 파일 처리 등을 시뮬레이션
    return "done"

# 리스트 컴프리헨션: 5번의 작업을 모두 실행해서 리스트로 만든다
list_job = [longtime_job() for i in range(5)]
print(list_job[0])  # 첫 번째 결과만 필요한 상황

실행하면 다음과 같은 결과를 출력한다.

job start
job start
job start
job start
job start
done

총 5초가 걸리고, "job start"가 5번 출력된 후 "done"이 출력된다.

이 코드의 문제점을 살펴보자. longtime_job() 함수는 1초씩 걸린다. 리스트를 만들 때 5번의 함수를 모두 미리 실행한다. 첫 번째 결과만 필요한데도 5초를 기다려야 한다.

이제 같은 작업을 제너레이터로 변경해 보자.

# generator2.py
import time

def longtime_job():
    print("job start")
    time.sleep(1)
    return "done"

# 제너레이터 표현식: 함수를 미리 실행하지 않고 필요할 때만 실행
[[MARK]]gen_job = (longtime_job() for i in range(5))[[/MARK]]
print(next(gen_job))  # 첫 번째 값만 요청

실행 결과는 다음과 같다.

job start
done

수행 시간도 1초로 단축되었다.

핵심 차이점:

  • [ ] (리스트 컴프리헨션)을 ( ) (제너레이터 표현식)으로 변경했다.
  • list_job[0]을 next(gen_job)으로 변경하여 값을 가져왔다.

제너레이터의 동작 방식:

(longtime_job() for i in range(5))는 코드를 즉시 실행하지 않는다. next(gen_job)을 호출할 때 비로소 첫 번째 longtime_job()만 실행한다. 나머지 4개는 실행되지 않는다.

제너레이터를 사용하면 성능이 크게 개선된다. 실행 시간이 5초에서 1초로 단축되었다. 리스트 컴프리헨션에서는 5개의 함수를 모두 실행했지만, 제너레이터 표현식에서는 필요한 첫 번째 함수만 실행했기 때문이다. "job start"가 5번 출력되던 것이 1번만 출력되는 것을 보면 함수 호출 횟수가 줄어든 것을 확인할 수 있다. 메모리 사용량도 절약되는데, 리스트는 모든 결과를 메모리에 저장하지만 제너레이터는 필요할 때만 값을 생성하기 때문이다.

이런 방식을 '느긋한 계산법(lazy evaluation)'이라고 한다. 미리 모든 값을 만들어 두지 않고 필요한 시점에 비로소 값을 계산한다는 뜻이다.

제너레이터는 다음과 같은 상황에서 매우 유용하다.

  • 대용량 데이터 처리 시 메모리 절약
  • 시간이 오래 걸리는 작업을 필요할 때만 실행
  • 무한한 데이터 스트림 처리
