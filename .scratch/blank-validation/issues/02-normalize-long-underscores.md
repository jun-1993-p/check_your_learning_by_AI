# 02: 긴 밑줄을 빈칸 하나로 정규화

**What to build:** LLM이 정답 자리를 `___`나 `________`처럼 어떤 길이의 밑줄로 쓰든 빈칸 하나로 세요. 그래서 학습자가 받는 빈칸 문제의 빈칸 수와 정답을 채운 문장이 맞아요("지운다지운다"가 사라져요). 앱 퀴즈, 시연 GUI, 정확도 평가가 모두 같은 빈칸 생성 함수를 거치므로 세 경로에 함께 적용돼요. 이 티켓에서 프로젝트 첫 단위 테스트(stdlib `unittest`, LLM 없이 실행)도 만들고, 먼저 지금 동작을 고정한 뒤 정규화를 추가해요.
