# 빈칸 검증: 긴 밑줄과 내용이 다른 여러 빈칸을 걸러내기

Status: needs-triage

## 문제

`quiz_templates.make_question()`은 LLM이 쓴 문제의 `____` 개수를 세기만 해서 두 경우를 통과시켜요 (`.idea_folder/데모_LLM_모델비교_20261013.md` 5장).

1. 내용이 다른 빈칸이 여러 개인데 정답은 하나
   - 예: `딕셔너리 ____에서 '____'의 Value를 얻기 위해 ____['____']을 사용한다.` (정답 a)
2. 긴 밑줄이 빈칸 여러 개로 집계됨
   - `________`(밑줄 8개)가 `blank_count=2`가 되어, 채우면 "지운다지운다"가 돼요.

Groq gpt-oss-20b에서도 나타났어요.

## 제안 (보고서 기준, 확정 아님)

- 밑줄 덩어리(`_{4,}`)를 먼저 `____` 하나로 정규화해요.
- 빈칸이 2개 이상이면 정답으로 채운 각 자리가 근거 인용에서 같은 단어인지 확인하고, 아니면 거부해요. 더 단순하게는 빈칸을 1개로 제한해요.
